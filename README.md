# Il Pistacchietto - Menu Digitale

Menu digitale multilingua per la gelateria Il Pistacchietto (Cernobbio).

## Funzionalità
- 7 lingue automatiche (IT, EN, DE, ES, FR, NL, RU)
- Foto da fotocamera/galleria
- Database ingredienti con autocompletamento
- Area gelataio protetta da PIN

## PIN gelataio
Default: `1234` - modificabile nel file src/App.jsx

## Sviluppo locale
\`\`\`
npm install
npm run dev
\`\`\`
